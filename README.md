# 🍹 Cocktail App

A modern web application for browsing cocktails using the Solvro Cocktails API.  
The app allows users to search, filter, and save favorite cocktails, as well as view detailed information about each drink.

---

## 🚀 Features

- Display list of cocktails
- Search cocktails by name
- Filter cocktails by category or ingredients
- Add cocktails to favorites
- View detailed information about each cocktail
- Responsive design
- Clean and modern UI

---

## 🛠️ Tech Stack

- React
- TypeScript
-  CSS
- Vite
- Solvro Cocktails API

---

## 🌐 API

Data is fetched from:

https://cocktails.solvro.pl
